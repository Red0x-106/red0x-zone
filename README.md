## Built With

- HTML
- CSS

The site is a frontend project and does not need a backend or server to run.

## How I Made It

I started by making the basic HTML structure for the different sections of the website.

After that, I worked on the CSS to make the site look the way I wanted instead of using a ready-made portfolio design.

I kept changing things while building it and tested the website in the browser to make sure the sections and links worked properly.

The main focus was making the website feel personal rather than making it look like a normal portfolio template.

## How to Use It

The website runs directly in a web browser, so there is nothing to install.

1. Open the red0x.zone website.
2. Scroll through the different sections.
3. Check the About Me and Stuff I Like sections.
4. Look through the projects.
5. Open the project links if you want to check out the projects.
6. Use the links section to visit the other places I'm active.

## What I Learned

While making this website, I got more practice with:

- HTML page structure
- CSS styling
- Making different sections work together
- Adding links between websites
- Organizing project information
- Making a website feel more personal
- Testing the layout in the browser

I also got more comfortable with making a website from my own idea instead of starting from a template.

## Problems I Had

One of the main things I had to figure out was how to make the website look like my own instead of making it feel like a normal portfolio.

I also had to test the layout and different sections while changing the CSS because changing one part could affect another part of the page.

Another thing I had to check was that all the project and social links worked correctly.

## Why I Made It

I made red0x.zone because I wanted one place where I could show the projects I've made and some things about me.

I also wanted to make the website myself instead of using a normal portfolio template.

This site is also a place where I can add more projects later as I keep making things.
